## 문서를 더할 때

- **장 번호는 파일을 가로질러 이어진다.** 다음 문서는 39장부터다
- `assets/doc.css` 를 링크한다. 문서마다 `<style>` 을 복사하지 않는다
- **기존 문서 전부의 `<nav>`** 에 새 문서를 넣고, `brand-sub` 의 `기획서 N/M` 을 전부 고친다
- 이 파일의 표에도 한 줄 더한다
- 다 쓴 뒤 교차 앵커를 검증한다 — 다른 파일의 장을 제 파일로 가리키는 실수가 실제로 있었다
